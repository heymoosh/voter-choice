# AI Agent Start Here

This repo uses the AI Coding Practices kit.

- **Before coding:** `bash scripts/ai-bootstrap.sh`, then follow **`AGENTS.md`** (the contract).
- **Adopting this kit into an existing repo?** Run `/adopt-existing-repo` first — don't copy blindly
  over the repo's own agent docs, commands, hooks, CI, or deploy config.
- **Human in a new repo:** run the bootstrap, then start Claude/Codex and describe what you want.
