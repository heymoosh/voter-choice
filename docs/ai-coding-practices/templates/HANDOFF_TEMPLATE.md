# Handoff Template

**Hard cap: ~20 lines.** A handoff is a goal-oriented pointer, not a log. Important details only.
The full record (run-by-run log, decisions, evidence) lives in a ledger / PR / design doc — **link
it, don't inline it.** If you're tempted to paste history, you're writing a log, not a handoff.

Copy the block below:

```
# Handoff: <topic>

Detail / full log: <link to ledger · PR · design doc>

- **Goal:** <the outcome we're driving to — 1 line>
- **Status:** <where it stands now — 1–2 lines>
- **Next action:** <the single next concrete step>
- **Blockers / awaiting:** <what's needed to proceed, or "none">
- **Key constraints:** <non-obvious rules that bite — up to 3 bullets>
```
